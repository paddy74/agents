## 3. Mermaid Generation Standards

Every Mermaid block generated by this skill must adhere to these rules:

1. **Explicit Graph Orientation**: Start every diagram with `graph TD` (top-down) or `graph LR` (left-to-right).
2. **Quoted Node Labels**: Wrap all node display text in double quotes (e.g., `A["Service Node (v2)"]`) so parentheses, brackets, colons, and hyphens never break parser syntax.
3. **Alphanumeric Node IDs**: Use clean alphanumeric identifiers (`User`, `AuthService`, `Artifact1`) without spaces or special characters.
4. **Directional Edge Labels**: Label every connector with an explicit verb phrase (e.g., `User -->|"Submits"| PromptDoc`).
5. **Concise Node Density**: Keep node labels under 12 words; insert `<br>` for clean line breaks rather than rendering wide horizontal boxes.
6. **Zero Speculation**: Represent only entities and relationships explicitly confirmed in the conversation.
