# My coding preferences

- Never commit directly to the default branch; work on a feature branch.
- Run the formatter before every commit.
- Write tests for every change you make.
- Prefer small functions that do one thing.
- Use type hints.
- Prefer pathlib over os.path.
- Ask before adding a new dependency.
- Don't leave commented-out code behind.
- Keep pull requests under about 400 changed lines.
